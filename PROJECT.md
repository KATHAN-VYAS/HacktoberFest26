# TerpCommons project

UMD student community for incoming, current and senior students. Supports a private AI answer before optional public escalation, discussions, events, communities and anonymous participation behind an account.

Active architecture: Next.js + React + Supabase Auth/PostgreSQL + Gemini and Open-Meteo. Production hosting is deferred at the owner's request. See README.md and SUPABASE_SETUP.md for current behavior and steps.

Migration changes only this GitHub checkout. The original parent-folder preview, D1 database and local posts remain separate. Hosted Supabase starts with curated sources and clearly marked synthetic sample conversations only.
